# MMC 隔离区与恢复目录分页

本次范围只包含生命周期操作记录的发现、选择与返回导航。普通实例扫描、删除策略和既有恢复／永久清理事务不变。

## 目录与分页契约

- 目录固定为所选游戏根的 `PCL/MmcLifecycle`，具体记录仍须是其直接子目录，名称为非空 GUID 的 `N` 格式。无法验证的文件、目录或日志作为无操作能力的诊断项保留。
- 新 Main 使用 `MmcInstanceLifecycleCatalog.ReadPage`，按操作目录 leaf 的 `StringComparer.Ordinal` 顺序前后翻页。枚举顺序不决定页内容。
- 默认每页最多 32 项，允许范围 1–256。页内累计受 pin 限制的日志／主定义源字节默认不超过 64 MiB，调用者可选择更小预算。既有验证 helper 的内部有界重读不计为新的源文件；此值不是物理 I/O 总字节的测量值。
- 枚举完整目录时只保留本页所需的有界候选 leaf、常量大小摘要和最小／最大 leaf，不先截断目录后排序，也不保留整份目录数组。
- 页中途达到字节预算时立即缩页；下一页从尚未读取的条目继续。单项自身超过所选预算时只产生该项的诊断，并保留继续翻页的入口。
- 原 `Read(root)` API 保留，作为最多 256 项的兼容预览；`Truncated` 仍提示存在后续记录。交互入口不再依赖这个截断预览。

## 游标范围与变化

`MmcLifecycleCatalogCursor` 没有公共构造器。它是内存内的导航边界，绑定规范化游戏根、页大小、字节预算、目录清单摘要及前／后 leaf 边界；不接受调用方传入的任意记录路径，不授予恢复或清理权限，也不写入持久存储。

目录摘要与文件系统枚举顺序无关，包含 leaf、属性、创建／修改时间、条目数和操作记录目录创建时间。成员新增、删除或可观察的目录替换使旧游标返回 `NeedsRefresh`；读取一页前后再次核对清单，变化中的列表不能沿用旧选择。

同 leaf 的日志内容每次加载页时重新读取。目录时间不是操作授权：即使外部修改没有改变可观察的目录清单，所选项在 `Execute` 或 `PreviewPurgeAsync` 中仍通过原有 intent pin、实例 ID、代数和预览指纹复核。恢复后端和永久清理后端继续复核各自的最终操作事实。

枚举、日志分块读取／哈希和主定义读取均检查取消令牌。关闭 Main 列表会取消并等待真实页读取返回；选择或确认期间不持有目录／日志 pin、admission 或设置暂停。

## Main 交互

使用现有 LF `ModpackDialogView`、`MyButton`、`MyListItem` 与模态选择端口：上一页、下一页、刷新列表、明确选择一条记录。新页、刷新、返回确认页后均不预选。移除的旧页控件不能重新赋予当前页选择。

诊断项查看后返回列表；取消恢复确认也返回原来的页，并重新读取该页。恢复完整隔离实例、撤销永久清理准备、继续已决定清理，以及明确永久清理，仍进入既有流程。切换游戏根后必须重新打开恢复列表。

## 定向证据边界

新增迁移用例 `MmcLifecycleCatalogPagingTests`：

- 一个真实生产 backend 隔离实例和 256 条 tiny 坏 GUID 记录，验证第 257 条可达、稳定前／后页及游标根／预算范围。
- 新增、删除、目录替换和同 leaf 日志破坏后的重读／拒绝；坏项不阻止后续合法隔离记录。
- 一个真实实例通过三次生产 Delete 在决定前取消留下三个合法 `Aborted` journal，用较小预算验证缩页不跳项；同时覆盖单项超预算及实际有界读取的取消。

新增 Native 用例 `MmcCatalogPagingUiChecks`：

- 实际 Main LF 列表／按钮／模态选择端口到达第 257 条，前后页、刷新、旧控件选择失效，取消确认后返回原页，再明确选择并恢复原 ID；关闭列表等待后台枚举返回。
- 确认期间替换 intent 后，实际 Main 操作失败，隔离内容和 world 字节保留，无成功发布。

根集成结果：Migration 与 Native 构建均为 0 警告／0 错误，Main 78 个既有警告／0 错误。
上述三项后端和两项实际 Main 用例全部通过；选择器 173 项通过，Sol max 定向只读审查未发现可证 P1/P2。
这些是独立自有记录与离屏控件证据，不声称真实用户隔离记录、桌面交互或 GTNH 游戏验收。
