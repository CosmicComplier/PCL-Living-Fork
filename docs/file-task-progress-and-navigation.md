# 本地文件任务的进度与浏览

存档备份、创建环境还原点、恢复世界和环境恢复通过实际读取、压缩、校验与复制的字节上报分段进度；多世界备份按世界分段。准备、写入与最终提交使用不同进度区间，原生加载器仅在负载成功结束后显示完成。取消不依赖显示进度：`LoaderFileOperation` 仍等待流、临时文件、finally 与回滚结束，再释放版本占用。

`McInstanceLock.IsLocked` 继续表示版本被文件任务占用，用于拒绝启动和冲突写入；`BlocksNavigation` 单独决定是否允许返回版本界面。创建快照允许浏览概览、Mod 和资源列表，版本设置与组件修改入口暂时受限。Mod 写入及资源修改也保留占用检查。恢复世界、环境恢复与包含未完成事务恢复的操作继续阻止进入版本设置。

备份目录、还原点清单只在完整写入后原子发布。读取已发布列表不再持有覆盖整个压缩或复制过程的操作锁，避免返回存档、还原点页面时等待后台任务。写入之间仍使用原有串行保护及跨进程锁；读取忽略并发清理后已被移走的记录，不将部分写入数据作为可恢复点。

`Test-BackupTaskProgress.ps1` 使用独立目录和真实 UI 任务负载，验证连续进度、两种恢复、快照期间浏览、读写互斥、列表读取与取消清理。`Test-WorldBackups.ps1`、`Test-EnvironmentHistory.ps1`、`Test-ReviewFixes.ps1` 验证存档、共享文件、校验、中断恢复与回滚。
