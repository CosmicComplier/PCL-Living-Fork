将来启动这些阶段时另立目标和验收，不扩大本目标的完成条件。

## 小任务与提交策略

完整功能链与兼容性是同一批次的双重验收条件，不能二选一。以用户可操作、可运行的功能链作为阶段交付单位，覆盖原入口、必要依赖、业务处理、存储／平台适配、界面反馈及回归；如界面或宿主仍未转换，只记录已完成的核心／前置范围，不将整条功能链标为完成。

每条链同步维护LF基线与迁移实现的行为／数据兼容矩阵，验证正常流程、异常、取消、回滚、文件锁、线程／界面交接及该链涉及的旧数据和升级入口。影响既有生产行为的差异须修正并通过相应真实Windows检查后才能验收；尚未验证的项目保留明确状态，不降低断言、删除旧样本或扩大捕获来取得通过。兼容适配围绕实际功能链所需边界推进，通用前置与局部规则提取不能替代整链交付。

内部仍可拆小任务和小批次提交，方便审查与定位回归；恢复后以能闭环的功能链安排实施和必要宿主前置，按实际完成的功能链及兼容证据报告进度，不以提交次数、方法提取数量、测试数量或C#增量作为整体完成率。

每个执行任务须有唯一编号、依赖、生产入口、改动边界、实际验收、状态和下一步。按依赖满足的最早任务执行；遇到阻塞先记录具体证据，再继续不依赖该阻塞的任务。若一个任务无法作为独立可审查批次完成，先在原任务下拆出子任务，并保留原依赖和完成条件，避免把模块名称长期当作没有出口的大任务。

独立且改动范围小的批次，在自审和相关实际检查通过后，可直接 commit、push 到迁移分支。跨模块、高风险或改动较大的批次，从子分支提交 PR 到迁移分支；先完成自审、构建、相关回归和必要的故障场景检查，再自行合并。PR 与 commit 均应说明行为变化、来源、验证和剩余限制。不得将未验证写为通过，不得以仅增加测试、文档或目标框架声明代替生产入口完成迁移。

commit 与 PR 使用明确标题和详细正文，尽量覆盖该批次实际修改。正文说明问题与目的、涉及的生产代码／配置／文档、关键行为和兼容边界、参考的 LF／CE／上游固定来源、实际验证命令与结果、未验证部分和后续事项。PR 描述面向未读聊天的审查者，说明最终实现和自审结论；范围变化时更新标题和正文。多行正文用 UTF-8 文件或结构化参数提交，保留真实换行。

续跑调度按小时触发。首次初始化和已有活动批次应避免重叠；每次以远端迁移分支及本账本作为续接依据。

每次续跑遵循以下顺序：

1. 读取本目标、状态账本、模块映射和适用的 `AGENTS.md`；确认分支，记录 `git status`、当前提交和未完成批次。
2. 识别未知本地改动及其归属。保留已有变更；不以 reset、clean、自动 stash 或覆盖文件消除冲突。只阻塞与未知变更重叠的操作，独立工作可继续。
3. 先收尾已开始且依赖满足的最早任务，再选账本中最早可执行项；只为实际变化修订计划。
4. 按生产功能链实现、自审并运行适当检查。Windows、GUI、账号、网络或发布检查没有实际环境时，分别记录未运行原因及后续动作。
5. 根据风险选择直接提交或子分支 PR，推送远端检查点。将实际提交、命令、结果、CI 链接、限制、下一步和阻塞写回账本，避免续跑重复劳动。
6. 所有验收完成后将目标标记 `completed`，暂停对应续跑调度；调度管理入口暂不可用时记录待暂停动作，并停止继续选取新任务。

临时构建产物、SDK、测试账号资料、访问凭据和机器私有路径不得作为迁移证据提交。并行协作按文件和任务分配所有权，集成者统一检查差异与提交，子代理不覆盖其他批次。

- 提交树清单中 LF 产品 VB 源文件为零。原有可选功能与生成源码均已转换，或在不降低约定能力的前提下以明确记录的等价方式替换；不通过隐藏、改扩展名或排除编译来减少数量。
- 主程序与 LF 自有依赖完成 .NET 10／WPF 的 Windows Debug、Release 构建、发布产物启动和实际运行验证；第三方及子模块框架兼容已有记录。
- 初始 LF 的回归脚本已适配新实现并实际执行。迁移新增测试通过真实生产入口运行；共享业务规则的无 WPF 测试只作为对应范围的证据。
- 账号、`Setup.ini`、版本隔离、游戏目录、用户修改、备份、还原点和更新通道使用旧数据样本完成对照；不将构造对象或纯源码断言当成完整账号或 GUI 验收。
- 按钮、滚动、页面加载、动画中断和叠加、窗口唤醒、单实例等 WPF 行为完成新旧对照。
- 安装、更新、备份、恢复等文件操作在取消或失败后等待负载、提交或回滚实际收尾，再释放版本占用；故障和恢复样本通过。
- 旧版更新桥、产物命名、凭据保护、资源解析和既有 MMC 等整合包能力保持等价；来源许可、模块清单、任务账本和最终证据同步完整。

初始 Windows 构建通过不等于新迁移批次通过；Linux 纯 C# 测试通过不等于 WPF 或完整启动链通过。任何未完成的必要验收均保持显式阻塞，目标不能提前标记完成。
