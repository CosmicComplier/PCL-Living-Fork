## 统一约束

所有后续入口仍须固定用户确认的身份／代数／摘要，验证来源与本地实际选择，不因 UI 选择绕过所有权。
活动／无法确认会话、未知路径和第三方改写必须保留内容；文件取消等待真实 I/O 结束。
重型验证单独串行，避免已观测到的机器 commit 压力，不修改系统 pagefile 或结束用户程序。
上表缺口未消除且取得对应证据前，不得把 goal 标记完成。
